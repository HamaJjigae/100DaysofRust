100 Days of Rust

Project Goals:
 - Networking and Server Development. TCP Sockets, multiple clients, request handling, some simple protocol. Towards an async server with tokio.
 - Concurrency and Parallelism. Learn threads, Arc, Mutex, atomics, channels, thread pools, and async tasks. Understand race conditions, contention and deadlocks.
 - Kafka Powered Chatroom. Build a chat server then introduce Kafka for distributing and persisting messages. Learn producers, consumers, partitions, offesets and delivery guarantees.
 - DB and networking. Build a small networked key-value store, or db-backed service. Measure throughput, latency, memory usages, batching and concurrency before optimizations.
 - Blockchain implementation. Build an educational blockchain with blocks, hashes, transaction validation, and chain verification. Later explore p2p networking and consensus.
